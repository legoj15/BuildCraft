###### Changes since 2026.3.1:

- **Fabric support for Minecraft 26.3 (in development).** BuildCraft now also builds for Fabric (with Fabric API and Forge Config API Port); the NeoForge versions are unchanged. Known Fabric differences so far: no Curios/Accessories slot for the Robot Goggles, bucket and fragile-fluid-shard icons show no fluid colour, and fluid transfers smaller than 1/81 mB are ignored.
