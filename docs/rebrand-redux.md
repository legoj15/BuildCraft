# Rebrand: BuildCraft Unofficial → BuildCraft Redux (2026.3.0+)

Scouted 2026-10-31. Takes effect with the first 2026.3.x release; nothing has shipped under 2026.3 yet,
so there is no in-family name split.

## The one rule: rename what players read, never the identifiers

`buildcraftunofficial` appears ~7,700 times in ~3,000 files: the mod id (`BCCore.MODID`), every
`assets/` and `data/` namespace, registry ids, lang keys, the config file name
(`buildcraftunofficial-common.toml`), game-test ids, recipe/advancement JSON, blueprints saved in worlds.
**It stays.** Changing it deletes every BuildCraft block, item and machine from every existing world,
resets configs, breaks saved blueprints, JEI/REI bookmarks, datapacks, KubeJS/CraftTweaker scripts and
any addon. NeoForge has per-entry registry aliases but nothing that migrates block-entity NBT, data
components, saved data, or config names, so a migration would be a multi-week project to buy a string
players only see with F3+H on. Precedent: plenty of mods keep a legacy id after a rename.

The copyright collective "the BuildCraftUnofficial contributors" (847 headers, allowlisted in
`CopyrightHeaderTester.ALLOWED_CLAIMS`) is the same kind of identifier. Recommendation: keep it. It is a
self-chosen name for our own claims, so renaming is legal, but it is an 847-file diff with zero player
value and it buries `git blame`. If the user wants it anyway: one mechanical sed, edit `ALLOWED_CLAIMS`
and the `SpaceToad && BuildCraftUnofficial` check at `CopyrightHeaderTester.java:263`, and the
"New file" line in AGENTS.md, in one commit of its own.

## Positioning vs BuildCraft Community Edition

BCCE (Modrinth `buildcraft-community-edition`, ~6.8k downloads) is BC 8.0 based and *also* restores
7.1.27 robotics, ships 1.19.2/1.20.1 Forge, 1.21.1/1.21.11/26.x NeoForge, and leads with an addon API.
So "robots" alone is not a differentiator. What is ours and verifiable from this repo:

- 1.21.10 support and one jar per MC line, NeoForge only, tested on every line (game tests per node).
- Robots checked behaviour-by-behaviour against a running 7.1.27 client
  (`docs/robotics-gameplay-audit.md`).
- Machines and robots act through the same calls a player does, so claim/protection mods hold.
- MJ with Forge Energy alongside, RF/FE display option, config gates (RF pipes, facades).
- JEI and REI, an in-game Guide Book with chapters and robot tutorials, Simplified Chinese.
- Laser targeting selectable between 7.x and 8.x behaviour; facade de-duplication.

Write the page about what Redux is, never about BCCE. One neutral FAQ line ("not affiliated with
BuildCraft Community Edition; don't install both") covers confusion. Before publishing that line, confirm
the two actually conflict — both likely ship `buildcraft.*` packages, which NeoForge rejects as a split
package — and phrase it from the result.
