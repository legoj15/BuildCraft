; Format
;   [c]       starts the glyph for character c (the one character between the brackets; [space] is U+0020)
;   9 rows    of '.' (empty) and '#' (ink), all the same width; that width is the glyph's width
;   ; ...     comment line
; Rows 0-6 sit on the baseline: cap height 7, x-height 5 (rows 2-6); rows 7-8 hold descenders.
; The pen advances by width + 1, so letters are 1 px apart. Lowercase is mostly 4 px wide, capitals 5.
