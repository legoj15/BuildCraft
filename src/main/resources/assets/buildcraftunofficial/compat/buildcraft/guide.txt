// ---------------------------------------------------------------------------
// The contents page is grouped by GAME SYSTEM first, then by subtype, then by page. Every
// entry below therefore carries a system (the first argument of every alias, see util.txt)
// and a subtype; the type (block / item / pipe / trigger / action) is still recorded, and
// still drives the older Sort By Type view, but inside a system it no longer decides the
// grouping. The system → subtype tree:
//
//   getting_started  tool (guide book, wrench) · gear · crafting (auto workbench)
//   power            engine · pipe_power (kinesis) · pipe_rf (FE) · power_delivery
//   transport        pipe_item · pipe_fluid · pipe_structure · pipe_plug · logistics ·
//                    inventory (container triggers)
//   logic            gate · wire · redstone · machine_control · pipe_plug (gate-adjacent
//                    plugs and their triggers/actions)
//   building         builders · markers · paperwork · tool
//   mining_fluids    mining · fluid · refining
//   silicon          crafting (laser tables) · laser · chipset
//   robots           robot · station · (board is reserved for the board pages)
//
// Entries sort alphabetically by their localized title inside a subtype, except where an
// entry carries an explicit TOC sort weight (the `_s` aliases, e.g. the Pipes below and the
// guide book itself) — lower weights sort earlier and a chapter inherits its lowest member's
// weight. Entries with a real `block/`, `item/`, or `pipe/` writeup and `place`-style stub
// entries (whose .md content lives at `placeholder/<name>.md`, or auto-stubs at runtime when
// missing) sit side-by-side in their natural system.
//
// alias reference (see util.txt — the system is ALWAYS the first argument):
//   block_engine   "<sys>" "<name>" "<stack>"   -> block/<name>.md   subtype=engine
//   block_mining   "<sys>" "<name>"             -> block/<name>.md   subtype=mining   (auto-stack)
//   block_fluid    "<sys>" "<name>"             -> block/<name>.md   subtype=fluid
//   block_refining "<sys>" "<name>"             -> block/<name>.md   subtype=refining
//   block          "<sys>" "<sub>" "<name>"     -> block/<name>.md   subtype=<sub>    (auto-stack)
//   pipe_item      "<sys>" "<name>" "<stack>"   -> pipe/<name>.md    subtype=pipe_item
//   pipe_fluid     "<sys>" "<name>" "<stack>"   -> pipe/<name>.md    subtype=pipe_fluid
//   pipe           "<sys>" "<sub>" "<name>" "<stack>" -> pipe/<name>.md  subtype=<sub>
//   gear           "<sys>" "<name>"             -> item/<name>.md    subtype=gear     (auto-stack)
//   tool           "<sys>" "<name>"             -> item/<name>.md    subtype=tool     (auto-stack)
//   tool_s         "<sys>" "<name>" "<sort>"    -> item/<name>.md    subtype=tool, weighted
//   plug           "<sys>" "<name>"             -> item/<name>.md    subtype=pipe_plug
//   paper          "<sys>" "<name>"             -> item/<name>.md    subtype=paperwork (auto-stack)
//   chipset        "<sys>" "<name>"             -> item/<name>.md    subtype=chipset  (auto-stack)
//   item_typed     "<sys>" "<sub>" "<name>" "<stack>" -> item/<name>.md  subtype=<sub>
//   trigger/action "<sys>" "<sub>" "<name>" "<statement id>" -> trigger|action/<name>.md
//   place          "<sys>" "<name>" "<type>" "<sub>" -> placeholder/<name>.md
//                  (used for stub entries — auto-stubs at runtime when no .md exists)
// ---------------------------------------------------------------------------
