<no_lore>
Filter is a gate action on the home station's pipe. It limits the items or fluids the linked robot will pick up or carry to those in its parameter slots.
</no_lore>

<chapter name="Information"/>
Put the items (or fluid containers) to allow in the parameter slots. A Carrier then loads only those items, a Picker collects only those, and a Tank robot takes only that fluid; everything else is left where it is. Several Filter actions on one gate add up. Needs a Quartz or Diamond gate for the parameter slots.
