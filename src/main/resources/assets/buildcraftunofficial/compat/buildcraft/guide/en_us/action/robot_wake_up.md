Up you get.
</lore>
<no_lore>
Wake Up is a gate action offered on any pipe that carries a Docking Station. It wakes a sleeping robot docked there at once.
</no_lore>

<chapter name="Information"/>
A robot that found nothing to do sleeps for a minute before trying again. Firing Wake Up ends the nap early, which is useful right after you refill its tool chest or paint a new zone. Pair it with the Sleep trigger on the same gate for a robot that never idles.
