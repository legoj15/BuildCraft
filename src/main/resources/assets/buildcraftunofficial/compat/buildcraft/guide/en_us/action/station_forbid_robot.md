Forbid Robot is a gate action offered on any pipe that carries a Docking Station. Robots matching its parameter may not use that station.
</no_lore>

<chapter name="Information"/>
Put a robot or a board in the parameter slot and every robot of that kind treats the station as if it did not exist: it will not dock, load, unload or recharge there. With the slot empty nothing is forbidden. Its opposite is Force Robot. Needs a Quartz or Diamond gate for the parameter slot.
