<lore>
Ask for what the machine next door needs.
</lore>
<no_lore>
Request Needed Items is a gate action offered on any pipe that carries a Docking Station, with three slots for exact items.
</no_lore>

<chapter name="Information"/>
This action is listed for completeness: in this version, as in BuildCraft 7.1, nothing reads it, so its orders are never delivered. Use Request Items or a Requester block to order items, and the Builder board to keep a Builder machine supplied.
