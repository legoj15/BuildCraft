<lore>
The third laser table. The Assembly Table makes parts and the Programming Table writes boards; this one puts things together: a written board into a robot.
</lore>
<no_lore>
The Integration Table combines a centre item with the items around it using laser power. Its one job today is programming a Robot with a Redstone Board.
</no_lore>
<chapter name="Using it"/>
Put the item to change in the centre slot and the parts to combine with it in the surrounding grid, then aim a powered <link inline="buildcraftunofficial:block/laser"/> at the table. The table shows the result it will make; when the laser has delivered the cost, the inputs are consumed and the result appears in the output slot. If nothing is shown, the combination is not a recipe: the grid must hold exactly the parts the recipe asks for, no more.
<chapter name="Programming a robot"/>
Centre a blank <link inline="buildcraftunofficial:item/robot"/>, add one written <link inline="buildcraftunofficial:item/redstone_board"/> beside it, and pay 5,000 MJ. The robot keeps whatever charge it had, and a fully drained one is topped up to 2,000 MJ so it can fly to a charging station straight away.
