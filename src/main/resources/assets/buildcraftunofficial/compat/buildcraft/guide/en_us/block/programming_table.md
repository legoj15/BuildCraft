<lore>
A laser table with a different job: instead of assembling chipsets it writes ideas onto redstone boards. Pick a job from the grid, feed it power, and out comes a board that knows what to do.
</lore>
<no_lore>
The Programming Table writes a job onto a blank Redstone Board. It is a laser table: it draws power from Lasers aimed at it and consumes the chosen board's cost before the written board appears.
</no_lore>
<chapter name="Using it"/>
Put a blank <link inline="buildcraftunofficial:item/redstone_board"/> in the input slot, pick a job from the grid of boards, and point a powered <link inline="buildcraftunofficial:block/laser"/> at the table. The progress bar fills with the laser's power; when it reaches the board's cost the input is consumed and the written board drops into the output slot. If the output slot is blocked the table waits. A written board can go back in and be rewritten to a different job, at the new job's full cost.
Boards cost 800, 3,200, 12,800 or 51,200 MJ depending on the job, so a tier of Lasers that is fine for chipsets takes a while on a Builder board. Every board page under Boards names its cost.
