<no_lore>
The Empty Board is the blank Redstone Board as the Programming Table lists it: choosing it costs nothing and writes nothing.
</no_lore>
<lore>
A board with no job. The Programming Table offers it at no cost, which is to say it offers to leave your board alone.
</lore>
<chapter name="Behaviour"/>
A robot carrying an empty board has no job and cannot be placed on a station; the game answers "Not programmed". Write a real board first.
