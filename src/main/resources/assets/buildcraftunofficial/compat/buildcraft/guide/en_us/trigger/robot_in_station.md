<lore>
Is a robot sitting on this station right now?
</lore>
<no_lore>
Robot In Station is a gate trigger offered on any pipe that carries a Docking Station. It is active while a robot is docked on that station.
</no_lore>

<chapter name="Requirements"/>
Visiting robots count as well as the station's own: a Carrier loading cargo, a Tank robot emptying, or a robot recharging on a kinesis pipe all make it fire. With a gate that has parameter slots, a robot or board in the slot narrows it to robots of that kind.
