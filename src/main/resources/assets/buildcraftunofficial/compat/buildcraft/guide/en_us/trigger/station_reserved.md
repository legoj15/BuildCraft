<lore>
Has some robot claimed this station?
</lore>
<no_lore>
Station Reserved is a gate trigger offered on any pipe that carries a Docking Station. It is active while any robot has taken the station, whether it lives there or is only visiting.
</no_lore>

<chapter name="Requirements"/>
Robots reserve a station before flying to it, so this fires a little before Robot In Station does and stays on until the robot releases the station again. Use it to keep a second robot from being sent to a busy dock.
