<lore>
Заставляет машину работать снова и снова.
</lore>
<no_lore>
«Цикл» — это действие гейта, доступное на любом гейте, установленном рядом с машиной, которая может работать.
</no_lore>

<chapter name="Требования"/>
Когда это действие активно, машина будет снова и снова завершать свой рабочий цикл.
Примечание: не все машины поддерживают действие «Цикл».

<chapter name="Направления триггеров"/>
Гейт может показывать действие «Цикл» несколько раз в разных цветах — по одному для каждой из подключённых машин.
Цвет действия обозначает направление, в котором находится машина относительно трубы, чтобы вы могли различать каждую из них.
