<lore>
Это включит машину,
</lore>
<no_lore>
«Вкл.» — это действие гейта, доступное на любом гейте, установленном рядом с машиной, которая может работать.
</no_lore>

<chapter name="Требования"/>
Когда это действие активируется, машина начнёт работать.
Примечание: не все машины поддерживают действие «Вкл.».

<chapter name="Направления триггеров"/>
Гейт может показывать действие «Вкл.» несколько раз разными цветами, обозначая каждую из подключённых машин.
Цвет действия соответствует направлению машины относительно трубы, чтобы вы могли различать каждую машину.
