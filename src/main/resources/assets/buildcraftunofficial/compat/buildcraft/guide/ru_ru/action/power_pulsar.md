<lore>
А вы знали, что с помощью гейта можно взять подключённый «Пульсар для труб» под активное управление?
</lore>
<no_lore>
«Энергетический пульсар» — это действие гейта, доступное на любом гейте, установленном на трубе, к которой подключён «Пульсар для труб».
</no_lore>

<chapter name="Требования"/>
Когда это действие активируется, «Пульсар для труб» включается, и труба начнёт получать энергию.

<link to="buildcraftunofficial:item/plug_pulsar"/>

<chapter name="Направления"/>
Гейт может показывать действие «Энергетический пульсар» несколько раз разными цветами, обозначая каждый подключённый «Пульсар для труб».
Цвет действия соответствует стороне трубы, на которой расположен «Пульсар для труб», чтобы вы могли различать каждый из них.
