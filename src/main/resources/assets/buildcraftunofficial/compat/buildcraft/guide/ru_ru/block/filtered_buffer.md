<no_lore>
Фильтрованный буфер принимает только те предметы, которые заданы в одном из 9 слотов фильтра.
</no_lore>
<chapter name="Информация"/>
Интерфейс представляет собой два ряда по девять слотов. В <bold>верхнем ряду</bold> задаются фильтры. Пустой слот фильтра означает, что в соответствующий слот не будет принят ни один предмет. <bold>Нижний ряд</bold> — это слоты буфера: по одному слоту инвентаря, принадлежащему фильтру над ним. Когда слот буфера пуст и для него задан фильтр, отображается предпросмотр допустимого предмета. Если пусты одновременно слот фильтра и слот буфера, слот закрывается и больше не принимает предметы.
