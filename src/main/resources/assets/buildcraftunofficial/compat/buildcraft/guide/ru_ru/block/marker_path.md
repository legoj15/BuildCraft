<lore>
Вместо того чтобы привязывать себя к объёмам, эта альтернативная технология позволяет задавать диагональные направленные пути.
</lore>
<no_lore>
Направляющие метки служат для создания путей в мире, которые могут использоваться другими блоками.
</no_lore>
<chapter name="Информация"/>
Чтобы соединить Направляющие метки, возьмите в руки Ключ для меток, и вы увидите потенциальные связи.
<link to="buildcraftunofficial:item/marker_wrench"/>
Наведите Ключ для меток на одну из связей и используйте его — между этими двумя Направляющими метками будет создан путь. Взаимодействуйте с самой Направляющей меткой, чтобы изменить направление пути.
