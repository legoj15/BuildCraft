<lore>
Картографический стол для рисования по миру. Раскрасьте поля, которые роботы могут возделывать, лес, который им можно рубить, карьер, где им можно добывать, — и передайте каждый рисунок гейту.
</lore>
<no_lore>
Планировщик зон показывает 3D-карту окружающей местности и позволяет рисовать на ней зоны кисточками. Нарисованная зона копируется на Карту расположения, по которой гейты сообщают роботам, где работать.
</no_lore>
<chapter name="Рисование зон"/>
Откройте планировщик и перетаскивайте пустой рукой, чтобы панорамировать карту, прокручивайте для масштабирования; отдалитесь до предела, чтобы получить обзорный вид загруженной местности. Возьмите <link inline="buildcraftunofficial:item/paintbrush"/> и перетащите её по карте, чтобы нарисовать зону этого цвета; перетаскивайте правой кнопкой, чтобы стирать. Планировщик хранит шестнадцать зон, по одной на каждый цвет, и запоминает их, когда вы его закрываете. Зоны — это столбы: нарисованный квадрат охватывает все высоты.
<chapter name="Копирование зон"/>
Поместите <link inline="buildcraftunofficial:map_location" type="item_stack"/> в выходной слот вместе с кисточкой цвета зоны, и планировщик запишет эту зону на карту. Входной слот делает обратное: переносит зону с Карты расположения в планировщик, причём кисточка рядом выбирает, какой цвет перезаписать. Карта расположения с записанной зоной помещается в слот параметров действия «Работать в области» на кварцевом или алмазном гейте; после этого робот работает только внутри нарисованного.
