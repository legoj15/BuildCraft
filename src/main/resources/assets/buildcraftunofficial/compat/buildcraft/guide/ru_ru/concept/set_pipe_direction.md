Трубы, работа которых зависит от того, в какую сторону они направлены, — например <link inline="buildcraftunofficial:pipe/iron_item"/> или <link inline="buildcraftunofficial:pipe/wood_item"/> с несколькими источниками извлечения — могут менять своё рабочее направление с помощью подключённого гейта. Для этого предусмотрено до 6 действий — по одному на каждую сторону.
Цветовая маркировка названий совпадает с цветовой маркировкой направленных сторон Алмазной транспортной трубы.
На всех трубах, кроме <link inline="buildcraftunofficial:pipe/daizuli_item"/>, доступные в гейте направления ограничены текущими соединениями трубы: если Железная транспортная труба выстроена в линию восток–запад и других соединений не имеет, доступны будут только Восток и Запад. У трубы, имеющей допустимые соединения по всем четырём сторонам света, а также сверху и снизу, в гейте можно будет задать любое из всех 6 направлений.
