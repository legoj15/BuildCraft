<lore>
Почему мои трубы постоянно соединяются? Как это остановить? Да просто поместите Заглушку для труб между ними.
</lore>
<no_lore>
Заглушка для труб — это модуль, который не даёт другим трубам и/или проводам труб соединяться между собой.
</no_lore>

<recipes stack="buildcraftunofficial:plug_blocker"/>

<chapter name="Соединения труб"/>
Её размещают непосредственно на любой стороне трубы, и любая труба, установленная рядом с этой стороны, не соединится.

Модули можно устанавливать только на трубах, причём с любой стороны трубы.
