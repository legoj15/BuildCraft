<lore>
Какого цвета двигатель рядом с гейтом? Он синий?
</lore>
<no_lore>
«Двигатель синий» — это триггер гейта, доступный на любом гейте, рядом с которым находится двигатель.
</no_lore>

<chapter name="Требования"/>
Когда этот триггер выбран, подключённые действия будут активироваться, только когда соседний двигатель находится на синей температурной стадии.

<chapter name="Направления триггеров"/>
Гейт может показывать триггер «Двигатель синий» несколько раз разными цветами, обозначая каждый из подключённых двигателей.
Цвет триггера соответствует направлению двигателя относительно трубы, чтобы вы могли различать каждый двигатель.
