<lore>
Какого цвета двигатель рядом с гейтом? Он красный?
</lore>
<no_lore>
«Двигатель красный» — это триггер гейта, доступный на любом гейте, рядом с которым установлен двигатель.
</no_lore>

<chapter name="Требования"/>
Когда он выбран, подключённые действия будут активироваться, только когда соседний двигатель находится на красной стадии температуры.

<chapter name="Направления триггеров"/>
Гейт может показывать триггер «Двигатель красный» несколько раз разными цветами, обозначая каждый из подключённых двигателей.
Цвет триггера соответствует направлению двигателя относительно трубы, чтобы вы могли различать каждый двигатель.
