<lore>
Есть ли жидкость в цистерне рядом с гейтом?
</lore>
<no_lore>
«Резервуар не пуст» — это триггер гейта, доступный на любом гейте, рядом с которым установлена цистерна.
</no_lore>

<chapter name="Требования"/>
После выбора подключённые действия будут активироваться, только когда в подключённой цистерне есть жидкость.

<chapter name="Параметры"/>
Если у триггера «Резервуар не пуст» и установленного гейта доступны параметры, слоты фильтра рядом с ним становятся доступными как параметр.
Разместив контейнер для жидкости в слотах фильтра, вы можете перед срабатыванием проверить, есть ли в цистерне жидкость, выбранная в слоте фильтра.

<chapter name="Направления триггеров"/>
Гейт может показывать триггер «Резервуар не пуст» несколько раз в разных цветах — по одному для каждой из подключённых цистерн.
Цвет триггера обозначает направление, в котором находится цистерна относительно трубы, чтобы вы могли различать каждую из них.
