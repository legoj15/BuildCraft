<lore>
Полна ли цистерна рядом с гейтом?
</lore>
<no_lore>
«Резервуар полон» — это триггер гейта, доступный на любом гейте, рядом с которым установлена цистерна.
</no_lore>

<chapter name="Требования"/>
После выбора подключённые действия будут активироваться, только когда в соседней цистерне не осталось места для приёма жидкостей.

<chapter name="Направления триггеров"/>
Гейт может показывать триггер «Резервуар полон» несколько раз в разных цветах — по одному для каждой из подключённых цистерн.
Цвет триггера обозначает направление, в котором находится цистерна относительно трубы, чтобы вы могли различать каждую из них.
