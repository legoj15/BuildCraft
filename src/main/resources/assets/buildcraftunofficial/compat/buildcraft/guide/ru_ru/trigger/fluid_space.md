<lore>
Есть ли в цистерне рядом с гейтом ещё место для жидкости?
</lore>
<no_lore>
«В резервуаре есть место» — это триггер гейта, доступный на любом гейте, рядом с которым установлена цистерна.
</no_lore>

<chapter name="Требования"/>
После выбора подключённые действия будут активироваться, только когда в подключённой цистерне есть место, чтобы принять ещё жидкости.

<chapter name="Параметры"/>
Если у триггера «В резервуаре есть место» и установленного гейта доступны параметры, слот фильтра рядом с ним становится доступным как параметр.
Разместив контейнер для жидкости в слоте фильтра, вы можете перед срабатыванием проверить, сможет ли цистерна принять жидкость, выбранную в фильтре.

<chapter name="Направления триггеров"/>
Гейт может показывать триггер «В резервуаре есть место» несколько раз в разных цветах — по одному для каждой из подключённых цистерн.
Цвет триггера обозначает направление, в котором находится цистерна относительно трубы, чтобы вы могли различать каждую из них.
