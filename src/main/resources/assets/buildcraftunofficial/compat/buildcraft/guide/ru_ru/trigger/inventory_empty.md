Эх, если бы существовал способ проверить, пуст ли сундук...
</lore>
<no_lore>
«Инвентарь пуст» — это триггер гейта, доступный на любом гейте, рядом с которым размещён инвентарь.
</no_lore>

<chapter name="Требования"/>
После выбора подключённые действия будут активироваться, только когда во всех подключённых инвентарях не останется предметов.

<chapter name="Направления триггеров"/>
Гейт может показывать триггер «Инвентарь пуст» несколько раз в разных цветах — по одному для каждого из подключённых инвентарей.
Цвет триггера обозначает направление, в котором находится инвентарь относительно трубы, чтобы вы могли различать каждый из них.
