<lore>
Действительно ли у машины рядом есть работа, которую она могла бы выполнять?
</lore>
<no_lore>
«Есть работа» — это триггер гейта, доступный на любом гейте, установленном рядом с машиной, которая может работать.
</no_lore>

<chapter name="Требования"/>
После выбора подключённые действия будут активироваться, только когда у соседней машины есть работа, которую она могла бы выполнять.

Примечание: не все машины поддерживают триггер «Есть работа».
