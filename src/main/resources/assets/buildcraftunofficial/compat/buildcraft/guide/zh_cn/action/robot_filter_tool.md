<no_lore>
过滤工具是一种门动作，位于母站所在的管道上。它将所关联的机器人会装备的工具，限制为参数槽位中所放的那些。
</no_lore>

<chapter name="信息"/>
伐木工板通常会拿走它在“提供物品”对接站找到的任何斧头。若过滤工具的参数槽位中放着一把钻石斧，它便只会装备钻石斧，宁愿休眠也不将就。参数槽位需要石英门或钻石门。
