<lore>
铁质和钻石能量管道的各款变体会对流经其中的能量进行节流。连接其上的门可以随意调高或调低节流量，将管道的传输上限切换为另一个速率。
</lore>
<no_lore>
“设置能量限制”是一组门动作，任何放置在铁质或钻石能量管道（MJ 与 RF 变体皆可）上的门都会提供这些动作。每个条目都会将管道的传输上限设为一个特定速率；选中其中一个，等同于用扳手右击管道，直到显示出该速率。
</no_lore>

<chapter name="行为"/>
MJ 动能管道（<link inline="buildcraftunofficial:pipe/iron_power"/>和<link inline="buildcraftunofficial:pipe/diamond_power"/>）提供七个 MJ/t 动作，从管道的最高传输速率一直降到 0 MJ/t。FE/RF 管道（<link inline="buildcraftunofficial:pipe/iron_rf"/>和<link inline="buildcraftunofficial:pipe/diamond_rf"/>）则以 RF/t 为单位提供同样的七档。选中 0 速率的条目会彻底阻断流经该管道的所有能量传输。
