# Robot Filter Tool

Use this tool and no other.

## Information

A Lumberjack normally takes any axe it finds at a Provide Items station. With Filter Tool holding a diamond axe it will only equip diamond axes, and sleep rather than settle for less. Needs a Quartz or Diamond gate for the parameter slots.
