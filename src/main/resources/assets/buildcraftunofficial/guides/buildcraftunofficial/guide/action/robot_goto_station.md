# Goto Station

Go and park over there.

## Information

With no parameter the robot simply re-docks where it is. With a Map Location in the parameter slot that points at a station (record the station's pipe face with the Map Location), the robot flies to that station and docks on it, interrupting whatever it was doing. Only Quartz and Diamond gates have action parameter slots.
