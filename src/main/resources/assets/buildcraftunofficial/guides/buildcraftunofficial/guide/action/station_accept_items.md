# Accept Items

Drop it here.

## Information

The cargo is pushed into the pipe the station sits on, so any item pipe will do; from there it travels like anything else in the pipe. A parameter slot with items in it limits what is accepted. Pickers, Carriers, Miners and the rest unload here. The gate must be firing for the action to count; a trigger that is always true (Redstone Signal Off with no redstone nearby) is the usual way to keep it on.
