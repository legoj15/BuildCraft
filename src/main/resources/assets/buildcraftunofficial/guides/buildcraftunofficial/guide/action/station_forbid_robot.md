# Forbid Robot

Not you.

## Information

Click the parameter slot with a programmed robot, or with an empty hand to cycle through the boards, and every robot of that kind treats the station as if it did not exist: it will not dock, load, unload or recharge there. With the slot empty nothing is forbidden. Its opposite is Force Robot. Needs a Quartz or Diamond gate for the parameter slot.
