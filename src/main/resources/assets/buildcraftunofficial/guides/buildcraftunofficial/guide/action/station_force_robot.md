# Force Robot

Only you.

## Information

Click the parameter slot with a programmed robot, or with an empty hand to cycle through the boards, and the station is reserved for robots of that kind; everyone else is turned away. Handy for keeping the Knight's sword chest away from the Butcher, or a charging dock free for the robot that matters. Needs a Quartz or Diamond gate for the parameter slot.
