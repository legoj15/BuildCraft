# Provide Fluids

Fill up here.

## Information

Like Provide Items, this only works through a Wooden fluid pipe whose extraction face points at the tank. A fluid container in the parameter slot limits what is offered. Tank robots fill up here. The gate must be firing for the action to count; a trigger that is always true (Redstone Signal Off with no redstone nearby) is the usual way to keep it on.
