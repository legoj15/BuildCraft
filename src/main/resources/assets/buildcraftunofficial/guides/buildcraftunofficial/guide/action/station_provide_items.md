# Provide Items

Help yourselves.

## Information

The station can only hand out what its pipe can reach: it must be a Wooden item pipe whose extraction face points at the inventory, exactly as if the pipe were extracting. A parameter slot with items in it limits what is offered; empty, everything in the inventory is on offer. Carriers, Delivery robots and every tool-using board fetch from here. The gate must be firing for the action to count; a trigger that is always true (Redstone Signal Off with no redstone nearby) is the usual way to keep it on.
