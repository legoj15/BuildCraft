# Request Items

I need five of these.

## Information

Each parameter slot holds an item and a count; a Delivery robot finds the order, loads the item at a Provide Items station and hands it in through this station's pipe. For more than a few orders, or to keep the deliveries in a chest, use a Requester block beside the pipe instead. Needs a Quartz or Diamond gate for the parameter slots.
