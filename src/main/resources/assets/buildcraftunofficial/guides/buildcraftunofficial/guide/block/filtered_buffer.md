# Filtered Buffer

<ItemImage id="buildcraftunofficial:filtered_buffer" scale="2" float="right" />

A more refined intermediate than having a chest collect items for temporary storage, the Filtered Buffer will only accept items if they match one of the 9 configurable slots.

## Information

The GUI is two rows of nine slots. The **top row** is where the filters are defined. An empty filter slot means nothing will be accepted for that slot. The **bottom row** are the buffer slots; a single slot of inventory space belonging to the filter above it. When a buffer slot is empty and a filter for that slot is defined, a preview of the valid item will be rendered. If both the filter slot and the buffer slot are empty, the slot becomes closed and will accept no more items.
