# Flood Gate

<ItemImage id="buildcraftunofficial:flood_gate" scale="2" float="right" />

With many large building projects, flooding large area's with fluids is a tedious task which you could do without.

## Information

The Floodgate is a power free machine which when fluids are piped into it will place them downwards into the world
