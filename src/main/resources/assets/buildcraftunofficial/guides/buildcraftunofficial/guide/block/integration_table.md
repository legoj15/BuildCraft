# Integration Table

<ItemImage id="buildcraftunofficial:integration_table" scale="2" float="right" />

The third laser table. The Assembly Table makes parts and the Programming Table writes boards; this one puts things together: a written board into a robot.

## Using it

Put the item to change in the centre slot and the parts to combine with it in the surrounding grid, then aim a powered [Laser](./laser.md) at the table. The table shows the result it will make; when the laser has delivered the cost, the inputs are consumed and the result appears in the output slot. If nothing is shown, the combination is not a recipe: the grid must hold exactly the parts the recipe asks for, no more.

## Programming a robot

Centre a blank [Robot](../item/robot.md), add one written [Redstone Board](../item/redstone_board.md) beside it, and pay 5,000 MJ. The robot keeps whatever charge it had, and a fully drained one is topped up to 2,000 MJ so it can fly to a charging station straight away.
