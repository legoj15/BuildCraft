# Electronic Library

<ItemImage id="buildcraftunofficial:library" scale="2" float="right" />

Instead of placing all your [Blueprint](../item/blueprint_clean.md) and [Template](../item/template_clean.md) into chests where they don't stack, put them into this digital database that functions like an Ender Chest!

## Information

The large window on the left side of the screen is the list of saved blueprints and templates (A.K.A. snapshots). Clicking on one selects it, where you can download its data or delete it.

Two slot rows on the right run the transfers:

- **Top row — Download (←)**: insert a used snapshot at the right slot. The arrow fills right-to-left as the data is loaded into the Library, then the same item drops out at left to signify that it is done. The snapshot now appears in the list.
- **Bottom row — Upload (→)**: with a snapshot in the list window selected, insert a snapshot item at the bottom left slot. The arrow fills left-to-right, and the selected blueprint will (over)write to your input and appear in the bottom right slot when ready.
