# Blueprint

<ItemImage id="buildcraftunofficial:blueprint_clean" scale="2" float="right" />

Your medium for capturing even the most minute of details of a structure. Slot one into an [Architect Table](../block/architect.md) to capture everything it can see, then load it into a [Builder](../block/builder.md) to manufacture an exact copy.

## Information

Insert a Blueprint into the input slot of an Architect Table bound to a Land Mark volume. When the scan finishes, the input blueprint is used (whether it is clean or already used) and is placed into the output slot with the new data written to it. The blueprint will show the name and a 3D snapshot of the captured structure in its tooltip.

To deploy the saved structure, slot the blueprint into a [Builder](../block/builder.md) and supply it with the same resources that were used at the time of the blueprint's capture.

If only the general shape of a structure is needed, see [Template](./template_clean.md) for faster scanning and simpler building.
