# Timer

<ItemImage id="buildcraftunofficial:plug_timer" scale="2" float="right" />

Making clocks more useful by putting them work with pipe logic!

## Information

The timer can be placed on any face of any pipe. When sharing a pipe with a gate, it will present three triggers for the gates to use.

- [5 Sec Timer](../trigger/timer_short.md)
- [10 Sec Timer](../trigger/timer_medium.md)
- [15 Sec Timer](../trigger/timer_long.md)
