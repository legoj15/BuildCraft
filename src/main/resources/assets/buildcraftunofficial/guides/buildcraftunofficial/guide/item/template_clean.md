# Template

<ItemImage id="buildcraftunofficial:template_clean" scale="2" float="right" />

Sometimes, you just need to erect something quick and dirty, you don't care what is made out of in the end, you just want that shape, and all you need is a template of sorts...

## Information

Insert a Template into the input slot of an [Architect Table](../block/architect.md) bound to a Land Mark volume When the scan finishes, the input blueprint is used (whether it is clean or already used) and is placed into the output slot with the new data written to it. The blueprint will show the name and a 3D snapshot of the captured structure in its tooltip.

To deploy the saved structure, slot the blueprint into a [Builder](../block/builder.md) and supply it with the same resources that were used at the time of the blueprint's capture.

If building every individual block 1:1 while even keeping the contents of chests, see [Blueprint](./blueprint_clean.md).
