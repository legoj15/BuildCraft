# Machine Off

Это выключит машину,

## Требования

Когда действие активировано, машина прекратит работу.

Примечание: не все машины поддерживают действие «Выкл.».

## Направления триггеров

Гейты могут показывать действие «Выкл.» несколько раз разными цветами — по одному на каждую подключённую машину.

Цвет действия обозначает направление машины относительно трубы, чтобы вы могли отличать машины друг от друга.
