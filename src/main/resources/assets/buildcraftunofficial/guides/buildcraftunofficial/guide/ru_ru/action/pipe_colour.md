# Окрасить проходящие предметы

Лазуритовая транспортная труба и Алмазуритовая транспортная труба позволяют окрашивать/сортировать окрашенные предметы; это действие может изменить цвет, используемый для окрашивания/сортировки.

## Требования

Когда действие активировано, гейт соответствующим образом настроит трубу:

Лазуритовая труба будет окрашивать предметы, проходящие через трубу, в цвет, выбранный действием «Окрашивать предметы».

Алмазуритовая труба будет отправлять в выбранном направлении только предметы, окрашенные в цвет, выбранный действием «Окрашивать предметы».
