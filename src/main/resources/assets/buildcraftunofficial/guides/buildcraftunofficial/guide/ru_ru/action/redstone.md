# Сигнал редстоуна

При срабатывании будет подан сигнал редстоуна.

## Требования

Когда это действие активировано, оно будет подавать сигнал редстоуна.

## Параметры

Когда у действия «Сигнал редстоуна» и у установленного гейта есть доступные параметры, «Только со стороны гейта» становится доступным в качестве параметра.

Выбор параметра «Только со стороны гейта» означает, что сигнал редстоуна будет подаваться только с той стороны, на которой установлен гейт.
