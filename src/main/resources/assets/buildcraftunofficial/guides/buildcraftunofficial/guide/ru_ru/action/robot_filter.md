# Robot Filter

Только эти, пожалуйста.

## Информация

Положите в слоты параметров предметы (или контейнеры с жидкостями), которые следует разрешить. Тогда «Носильщик» загружает только эти предметы, «Сборщик» собирает только их, а «Резервуар» забирает только эту жидкость; всё остальное остаётся на месте. Несколько действий «Фильтр» на одном гейте складываются. Для слотов параметров требуется кварцевый или алмазный гейт.
