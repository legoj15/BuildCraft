# Robot Filter Tool

Используйте этот инструмент и никакой другой.

## Информация

Дровосек обычно берёт любой топор, который найдёт на станции «Предоставить предметы». Если в «Фильтрующем инструменте» лежит алмазный топор, он будет экипировать только алмазные топоры и скорее уснёт, чем согласится на меньшее. Для слотов параметров требуется кварцевый или алмазный гейт.
