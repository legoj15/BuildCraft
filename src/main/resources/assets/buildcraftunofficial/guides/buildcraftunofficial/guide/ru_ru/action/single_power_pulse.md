# Одиночный энергетический пульс

А вы знали, что можно заставить подключённый «Пульсар для труб» выдать всего один пульс?

## Требования

Когда это действие активируется, Пульсар для труб включается на короткое время, и труба получает достаточно энергии для завершения одной операции.

- [Пульсар для труб](../item/plug_pulsar.md)

## Направления

Гейт может показывать действие «Одиночный энергетический пульс» несколько раз разными цветами, обозначая каждый из подключённых Пульсаров для труб.

Цвет действия соответствует направлению Пульсара для труб относительно трубы, чтобы вы могли различать каждый Пульсар для труб.
