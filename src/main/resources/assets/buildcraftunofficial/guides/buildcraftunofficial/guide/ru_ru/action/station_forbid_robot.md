# Запретить робота

Не ты.

## Информация

Щёлкните по слоту параметра запрограммированным роботом — или пустой рукой, чтобы перебирать платы, — и каждый робот такого типа будет вести себя так, будто станции не существует: он не станет ни стыковаться к ней, ни загружаться, ни разгружаться, ни подзаряжаться. Если слот пуст, ничего не запрещено. Запрещённый робот, живущий на станции, покидает её, но продолжает считать её своим домом и возвращается, когда гейт разрешит ему; до тех пор ни один другой робот не может ею пользоваться. Его противоположность — «Принудить робота». Для слота параметра нужен кварцевый или алмазный гейт.
