# Автоматический верстак

<ItemImage id="buildcraftunofficial:autoworkbench_item" scale="2" float="right" />

Как и подобает каждому инженеру, вы ощущаете потребность автоматизировать всё вокруг. Ручной крафт — утомительное занятие, так почему бы не автоматизировать и его?

## Информация

Автоматический верстак позволяет крафтить предметы автоматически, без вашего участия. Просто задайте рецепт предмета, который хотите получить, и подавайте в верстак предметы по трубам.

<Row>
<RecipesFor id="buildcraftunofficial:autoworkbench_item" fallbackText="" />
</Row>

Просто подайте по трубам ресурсы, которые требует заданный внутри рецепт, и верстак будет медленно крафтить предмет или блок, не расходуя энергию.
