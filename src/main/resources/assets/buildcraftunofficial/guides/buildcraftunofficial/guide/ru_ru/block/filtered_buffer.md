# Фильтрованный буфер

<ItemImage id="buildcraftunofficial:filtered_buffer" scale="2" float="right" />

Более совершённое промежуточное звено, чем сундук, собирающий предметы для временного хранения: Фильтрованный буфер принимает только предметы, соответствующие одному из 9 настраиваемых слотов.

## Информация

Интерфейс представляет собой два ряда по девять слотов. В **верхнем ряду** задаются фильтры. Пустой слот фильтра означает, что в соответствующий слот не будет принят ни один предмет. **Нижний ряд** — это слоты буфера: по одному слоту инвентаря, принадлежащему фильтру над ним. Когда слот буфера пуст и для него задан фильтр, отображается предпросмотр допустимого предмета. Если пусты одновременно слот фильтра и слот буфера, слот закрывается и больше не принимает предметы.
