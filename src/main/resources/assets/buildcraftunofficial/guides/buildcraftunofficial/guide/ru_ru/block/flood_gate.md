# Шлюз

<ItemImage id="buildcraftunofficial:flood_gate" scale="2" float="right" />

При многих крупных строительных проектах заливка больших площадей жидкостями — утомительное занятие, без которого можно обойтись.

## Информация

Шлюз — это машина, не требующая энергии: если подать в неё жидкости по трубам, он разместит их в мире под собой.
