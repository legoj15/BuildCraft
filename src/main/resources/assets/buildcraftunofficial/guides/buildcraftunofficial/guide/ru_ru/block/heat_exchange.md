# Теплообменник

<ItemImage id="buildcraftunofficial:heat_exchange" scale="2" float="right" />

В попытках извлечь максимум пользы из своего горючего топлива одних прохладных жидкостей уже недостаточно — появляется необходимость нагревать и охлаждать жидкости до различных температур.

## Информация

Теплообменник используется для охлаждения/нагрева жидкостей и состоит из 3 частей: начала, середины и конца, которые собираются вместе, образуя мультиблок.

Можно использовать до 3 средних секций, чтобы ускорить процесс.

Если нагреть прохладное топливо до горячего состояния, оно будет гореть лучше в Двигателе внутреннего сгорания. Нефть, найденная в Нижнем мире, уже жгучая, так что сначала охладите её.
