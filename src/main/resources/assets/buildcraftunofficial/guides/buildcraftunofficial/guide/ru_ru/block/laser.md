# Лазер

<ItemImage id="buildcraftunofficial:laser" scale="2" float="right" />

С точки зрения логистической эффективности ничто не сравнится с использованием чистой энергии для выполнения работы.

## Информация

Лазер видит конус длиной 6 блоков в направлении, куда он смотрит, и отслеживает каждый блок-цель лазера внутри этого конуса. Гаечный ключ может повернуть его после установки. Если цели нужна энергия, Лазер фиксируется на ней, и их соединяет видимый красный луч. Если в зоне действия несколько целей и всем нужна энергия, Лазер переключается между ними, по кругу распределяя свою пропускную способность каждые несколько тиков.

Несколько лазеров могут быть направлены на одну и ту же машину.

## Энергия

Лазеру для работы требуется энергия MJ, и он принимает её с любой стороны блока. Если энергии поступает достаточно, он будет разгоняться, что отображается разными цветами лазера.
