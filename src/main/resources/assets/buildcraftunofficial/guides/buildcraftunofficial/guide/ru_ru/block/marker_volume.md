# Метка

<ItemImage id="buildcraftunofficial:marker_volume" scale="2" float="right" />

Контролировать, где должны работать ваши машины, очень важно при строительстве — иначе они могут выйти из-под контроля.

## Информация

Чтобы разметить область, необходимо соединить ваши Метки, чтобы область была задана.

Чтобы соединить Метки, разместите их на одной оси мира друг относительно друга и нажмите на них.

<Row>
<RecipesFor id="buildcraftunofficial:marker_volume" fallbackText="" />
</Row>

**Используется для крафта:** <ItemLink id="buildcraftunofficial:architect" />, <ItemLink id="buildcraftunofficial:builder" />, <ItemLink id="buildcraftunofficial:filler" />

После этого появится лазер, соединяющий их. Метки могут соединяться ещё с 6 метками по 6 осям, но для создания размеченного Метками куба на самом деле достаточно и 4.

Метки соединяются друг с другом на расстоянии не более 64 блоков, что может ограничить простор для творчества.

Подача сигнала редстоуна на Метку заставит её испускать постоянные лазеры, показывающие, куда можно поставить другие Метки, чтобы они соединились.
