# Планировщик зон

<ItemImage id="buildcraftunofficial:zone_planner" scale="2" float="right" />

Картографический стол для рисования по миру. Раскрасьте поля, которые роботы могут возделывать, лес, который им можно рубить, карьер, где им можно добывать, — и передайте каждый рисунок гейту.

## Рисование зон

Откройте планировщик и перетаскивайте пустой рукой, чтобы панорамировать карту, прокручивайте для масштабирования; отдалитесь до предела, чтобы получить обзорный вид загруженной местности. Возьмите [Кисточка](../item/paintbrush.md) и перетащите её по карте, чтобы нарисовать зону этого цвета; перетаскивайте правой кнопкой, чтобы стирать. Планировщик хранит шестнадцать зон, по одной на каждый цвет, и запоминает их, когда вы его закрываете. Зоны — это столбы: нарисованный квадрат охватывает все высоты.

## Копирование зон

Поместите <ItemLink id="buildcraftunofficial:map_location" /> в выходной слот вместе с кисточкой цвета зоны, и планировщик запишет эту зону на карту. Входной слот делает обратное: переносит зону с Карты расположения в планировщик, причём кисточка рядом выбирает, какой цвет перезаписать. Карта расположения с записанной зоной помещается в слот параметров действия «Работать в области» на кварцевом или алмазном гейте; после этого робот работает только внутри нарисованного.
