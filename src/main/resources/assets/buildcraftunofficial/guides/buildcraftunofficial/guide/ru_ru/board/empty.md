# Пустая плата

Плата без работы. Стол программирования предлагает её бесплатно — иными словами, предлагает оставить вашу плату в покое.

## Поведение

Робот с пустой платой не имеет работы и не может быть поставлен на станцию — игра отвечает «Не запрограммирован». Сначала запишите настоящую плату.
