# Плата садовника

Ножницы с крыльями. Деревьям — стрижка; стволы — работа для кого-то другого.

## Поведение

Робот вооружается ножницами со станции «Предоставить предметы» внутри своей зоны и состригает каждый найденный там блок листвы. Выпавшие предметы падают на землю. Программирование стоит 3,200 MJ.
