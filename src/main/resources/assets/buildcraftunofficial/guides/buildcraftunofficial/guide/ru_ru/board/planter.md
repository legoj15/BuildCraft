# Плата сажальщика

Дайте ей мешок семян — и она сама найдёт для вас свободную землю.

## Поведение

Робот берёт семена, саженцы или другие пригодные для посадки предметы со станции с действием «Предоставить предметы» внутри своей зоны, затем ищет место, где растение сможет расти, подлетает туда и сажает его. Он не станет сажать там, где культура не выживет, поэтому тёмное поле остаётся пустым, пока его не осветят. Программирование стоит 3,200 MJ.
