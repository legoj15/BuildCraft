# Pipe Signals

Для каждого из 16 цветов провода трубы можно отправлять и принимать уникальный сигнал другим гейтам и от них.

Провод в более тёмном, не запитанном состоянии считается выключенным. Когда по проводу проходит сигнал, он начинает светиться — это значит, что он включён.

## Как действие

Подача сигнала трубы выполняется на стороне действий гейта. Выберите цвет сигнала трубы, который хотите отправить, и при срабатывании гейта он активируется, из-за чего провод трубы соответствующего цвета начнёт светиться.

- [Pipe Wires](../item/wire.md)

## Как триггер

У каждого цвета сигнала трубы есть два состояния триггера: «Сигнал трубы вкл.» срабатывает, когда провод трубы этого цвета светится, а «Сигнал трубы выкл.» — когда провод трубы этого цвета *не* светится.

## Параметры

Когда у гейта есть свободные слоты параметров, варианты «Сигнал трубы вкл.» и «Сигнал трубы выкл.» для каждого цвета подключённого провода становятся доступными как параметры. Добавление такого параметра в **триггер** означает, что гейт сработает, только когда этот второй провод примет требуемое состояние, — так можно требовать совпадения состояний нескольких проводов перед активацией действия.

Добавление такого параметра в **действие** равносильно активации провода трубы этого цвета, поэтому у гейта с 1 параметром действия каждый слот действия сможет активировать 2 провода труб.
