# Set Pipe Direction

Трубы, работа которых зависит от того, в какую сторону они направлены, — например [Железная транспортная труба](../pipe/iron_item.md) или [Деревянная транспортная труба](../pipe/wood_item.md) с несколькими источниками извлечения — могут менять своё рабочее направление с помощью подключённого гейта. Для этого предусмотрено до 6 действий — по одному на каждую сторону.

Цветовая маркировка названий совпадает с цветовой маркировкой направленных сторон Алмазной транспортной трубы.

На всех трубах, кроме [Алмазуритовая транспортная труба](../pipe/daizuli_item.md), доступные в гейте направления ограничены текущими соединениями трубы: если Железная транспортная труба выстроена в линию восток–запад и других соединений не имеет, доступны будут только Восток и Запад. У трубы, имеющей допустимые соединения по всем четырём сторонам света, а также сверху и снизу, в гейте можно будет задать любое из всех 6 направлений.
