# Set Power Limit

Железные и алмазные варианты энергетических труб ограничивают проходящую через них энергию. Подключённый гейт может по своему усмотрению поднимать и опускать это ограничение, переключая предел передачи трубы на другое значение.

## Поведение

Кинетические трубы для MJ ([Железная кинетическая труба](../pipe/iron_power.md) и [Алмазная кинетическая труба](../pipe/diamond_power.md)) предоставляют семь действий с пределами в MJ/т — от полной скорости передачи трубы до 0 MJ/т. Трубы FE/RF ([Железная FE-труба](../pipe/iron_rf.md) и [Алмазная FE-труба](../pipe/diamond_rf.md)) предоставляют те же семь шагов в RF/т. Выбор пункта со значением 0 полностью блокирует любую передачу энергии через трубу.

- [Железная кинетическая труба](../pipe/iron_power.md)
- [Алмазная кинетическая труба](../pipe/diamond_power.md)

Доступно, когда включена совместимость с FE:

- [Железная FE-труба](../pipe/iron_rf.md)
- [Алмазная FE-труба](../pipe/diamond_rf.md)

Конкретные значения, показанные в каждом пункте, зависят от самой трубы. Гейт каждой трубы предлагает только семь действий, соответствующих её собственной таблице передачи.
