# Блок объёма

<ItemImage id="buildcraftunofficial:volume_box" scale="2" float="right" />

Блок объёма доступен только в творческом режиме или при включённых читах. Управлять им можно Ключом для объёма.

- [Ключ для объёма](./volume_wrench.md)

Нажмите Ключом для объёма на тот угол, который хотите переместить, и двигайтесь туда, куда смотрите, — размер Блока объёма будет меняться вместе с вами.

Снова нажмите ключом там, где хотите остановить его перемещение, и он остановится. Вы можете щёлкнуть по нему с зажатым Shift Ключом для объёма или Ключом для меток, чтобы полностью удалить Метку объёма

*Только творческий режим: рецепта для выживания нет.*
