# Отладчик

<ItemImage id="buildcraftunofficial:debugger" scale="2" float="right" />

## Информация

Инструмент, доступный только при включённых читах. Если держать его в руке в режиме выживания, меню отладки F3 покажет те дополнительные данные, которые обычно видны игрокам в творческом режиме. Некоторые блоки при взаимодействии открывают дополнительные отладочные возможности.

**Действие по правому клику.** Правый клик по блоку BuildCraft, для которого зарегистрирована отладочная подсветка, выводит сообщение с описанием того, что подсвечивается, и запускает отрисовку этой подсветки поверх блока. Правый клик по другому поддерживаемому блоку переносит подсветку на новую цель. Подсветка исчезает сама, как только запомненный блок сломан, выгружен или заменён чем-то другим.

**Улучшение экрана F3.** Откройте экран отладки F3 и посмотрите на любой блок BuildCraft — если вы держите Отладчик в одной из рук или находитесь в творческом режиме, в нижних углах экрана появятся дополнительные строки **[BC]**, перечисляющие всё зарегистрированное внутреннее состояние — обычно запас энергии, прогресс работы, содержимое жидкостей и т. п.

## Охват подсветки

Сейчас два блока BuildCraft рисуют подсветку в мире при правом клике с Отладчиком в руке:

**[Карьер](../block/quarry.md):** полупрозрачный зелёный параллелепипед накрывает каждый чанк, который Карьер принудительно держит загруженным, слегка отступая от границы каждого чанка, чтобы соседние чанки читались как отдельные объёмы. Помогает проверить, какие и сколько чанков Карьер держит загруженными во время своей работы.

**[Лазер](../block/laser.md):** маленькие кубики помечают каждый блок внутри шестиблочного прицельного конуса Лазера. Зелёные кубики доступны — между ними и Лазером есть свободная прямая; красные — заблокированы промежуточным блоком. Помогает разобраться, почему Лазер не питает свою цель.

На данный момент ни у каких других блоков нет подобных дополнительных средств отладки.

*Только творческий режим: рецепта для выживания нет.*
