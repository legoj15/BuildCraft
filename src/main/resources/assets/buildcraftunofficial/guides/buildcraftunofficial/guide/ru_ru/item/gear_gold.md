# Золотая шестерня

<ItemImage id="buildcraftunofficial:gear_gold" scale="2" float="right" />

Более сложные задачи требуют множества очень маленьких сцепленных шестерён, а железные шестерни при таком использовании легко ломаются.

Золото никогда не ломается, когда из него изготавливают крошечные шестерни, что позволяет использовать его в сложных механизмах.
