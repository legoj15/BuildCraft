# Фасад

<ItemImage id="buildcraftunofficial:plug_facade" scale="2" float="right" />

Трубы не вписываются в стиль вашей постройки? Просто поместите на них фасад из подходящего блока, чтобы он соответствовал постройке и спрятал их.

## Варианты фасадов

Почти любой блок в игре можно превратить в фасад и установить на боковую сторону трубы.

Сплошной фасад заблокирует любые соединения труб, если разместить его между ними.

Полый фасад позволит трубам соединяться сквозь него.
