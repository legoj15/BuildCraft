# Световой датчик

<ItemImage id="buildcraftunofficial:plug_light_sensor" scale="2" float="right" />

Световой датчик позволяет использовать силу света для управления вашими гейтами.

## Механика модулей

Эти данные позволяют соседнему гейту через триггеры «Ярко» и «Темно» определять, светло сейчас или темно.

С помощью триггеров «Ярко» и «Темно» можно запускать действие через гейт.

- [Light Bright](../trigger/light_high.md)
- [Light Dark](../trigger/light_low.md)

## Соединения труб

Модули можно устанавливать только на трубах, причём с любой стороны трубы.

При размещении между двумя трубами он заблокирует любые другие соединения труб и проводов труб.
