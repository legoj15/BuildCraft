# Энергетический адаптер для труб

<ItemImage id="buildcraftunofficial:plug_power_adaptor" scale="2" float="right" />

Пульсар для труб — полезное усовершенствование по сравнению с питанием деревянных труб от двигателей, но он кажется... неполным. Было бы полезно, если бы существующую энергосеть и двигатели можно было использовать для питания труб извлечения на большей скорости.

## Механика модулей

Его можно устанавливать только на трубы, принимающие энергию, и любая кинетическая труба, размещённая рядом с ним, подключится.

Энергия, подаваемая через подключённую кинетическую трубу, сможет питать подключённую транспортную/жидкостную трубу, принимающую энергию.

## Соединения труб

Модули можно устанавливать только на трубах, причём с любой стороны трубы.

Он остановит любое другое соединение труб и проводов труб между двумя трубами при размещении между ними, кроме кинетических труб и его самого.
