# Пульсар для труб

<ItemImage id="buildcraftunofficial:plug_pulsar" scale="2" float="right" />

Снабжать трубы энергией бесплатно, без необходимости в большом двигателе? Ну разве это не круто.

## Механика модулей

Его можно установить только на трубу, принимающую энергию, а для активации — щёлкнуть по нему правой кнопкой мыши.

Активировать «Пульсар для труб» можно также с помощью гейта, используя действия пульсара.

- [Энергетический пульсар](../action/power_pulsar.md)
- [Одиночный энергетический пульс](../action/single_power_pulse.md)

## Соединения труб

Модули можно устанавливать только на трубах, причём с любой стороны трубы.

Установленный между двумя трубами, он остановит любые другие соединения труб и проводов труб между ними.
