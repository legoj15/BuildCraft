# Док-станция

<ItemImage id="buildcraftunofficial:robot_station" scale="2" float="right" />

Насест для робота, прикрученный к боку трубы. От того, к какой трубе его прикрутить, зависит, что робот сможет там делать.

## Установка

Щёлкните правой кнопкой по любой грани трубы, чтобы установить станцию на неё. Затем щёлкните правой кнопкой по станции запрограммированным [Робот](./robot.md), чтобы поставить робота: эта станция становится домом робота, и робот **соединён** с ней. Перед домашней станцией робота должны находиться два свободных блока. Присядьте и щёлкните по роботу гаечным ключом, чтобы забрать его (робот с инструментом сначала отдаёт инструмент).

## Что решает труба

На кинетической (энергетической) трубе станция подзаряжает пристыкованного робота от энергии трубы. На **Деревянной транспортной трубе** станция может выдавать предметы из инвентаря, на который направлена сторона извлечения трубы, а на Деревянной жидкостной трубе — так же выдавать жидкость. На любой транспортной трубе станция может принимать груз от робота и проталкивать его в трубу. Станция на булыжниковой трубе, к примеру, может только принимать доставки.

## Что решает гейт

Для подзарядки гейт не нужен, но ни одна из описанных выше передач предметов и жидкостей не происходит без разрешения гейта на трубе станции. Действия станции:

- [Предоставить предметы](../action/station_provide_items.md)
- [Принимать предметы](../action/station_accept_items.md)
- [Предоставить жидкости](../action/station_provide_fluids.md)
- [Принимать жидкости](../action/station_accept_fluids.md)
- [Запросить предметы](../action/station_request_items.md)
- [Запросить необходимые предметы](../action/station_request_needed_items.md)
- [Запретить робота](../action/station_forbid_robot.md)
- [Принудить робота](../action/station_force_robot.md)

«Запретить робота» и «Принудить робота» принимают в качестве параметра тип робота (щёлкните по слоту запрограммированным роботом или пустой рукой, чтобы перебирать платы) и, соответственно, не подпускают к станции роботов такого типа или резервируют её для них. «Запросить предметы» запрашивает предмет у пролетающих мимо роботов-разносчиков — как однослотовый [Инициатор запроса](../block/requester.md). Гейт также может считывать состояние станции:

- [Робот на станции](../trigger/robot_in_station.md)
- [Станция соединена](../trigger/station_linked.md)
- [Станция зарезервирована](../trigger/station_reserved.md)
- [Robot Sleep](../trigger/robot_sleep.md)

А приказы, которые домашняя станция отдаёт своему роботу, — это действия робота:

- [Работать в области](../action/robot_work_in_area.md)
- [Перемещение на станцию](../action/robot_goto_station.md)
- [Разбудить](../action/robot_wake_up.md)
- [Robot Filter](../action/robot_filter.md)
- [Robot Filter Tool](../action/robot_filter_tool.md)
