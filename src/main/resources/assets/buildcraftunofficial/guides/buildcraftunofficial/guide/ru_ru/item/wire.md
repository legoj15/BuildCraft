# Pipe Wires

<ItemImage id="buildcraftunofficial:wire_orange" scale="2" float="right" />

Редстоун: проходит лишь 15 блоков, несёт только один сигнал на блок и бывает только красным (какая скука).

Провод трубы: идёт бесконечно далеко, может нести множество сигналов на трубу и доступен во множестве цветов.

## Механика проводов

Гейт подаёт сигнал на провод трубы, и тот передаётся другим подключённым проводам трубы того же цвета.

Сигнал может быть только включён или выключен и проходит неограниченное расстояние (в отличие от редстоуна).

Провод трубы доступен во всех 16 цветах.

## Размещение провода

Провод трубы размещается на каждой стороне трубы и соединяется только с проводами трубы того же цвета, идущими от него в направлениях по сторонам света.

Провода одного цвета соединяются и через разные трубы, даже если сами трубы друг с другом не соединены.

- [Pipe Signals](../concept/pipe_signals.md)

## Доступные цвета

Для каждого цвета красителя существует свой предмет — провод трубы. Рецепт одинаков для всех цветов — меняется только краситель, — поэтому стоимость на Сборочном столе одна и та же для любого оттенка.
