# Двигатель зелёный

Какого цвета двигатель рядом с гейтом? Он зелёный?

## Требования

При выборе этого триггера подключённые действия будут активироваться, только когда соседний двигатель находится на зелёной температурной стадии.

## Направления триггеров

Гейт может показывать триггер «Двигатель зелёный» несколько раз разными цветами, обозначая каждый из подключённых двигателей.

Цвет триггера соответствует направлению двигателя относительно трубы, чтобы вы могли различать каждый двигатель.
