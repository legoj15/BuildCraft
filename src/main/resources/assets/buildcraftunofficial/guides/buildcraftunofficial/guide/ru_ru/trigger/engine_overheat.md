# Перегрев двигателя

Какого цвета двигатель рядом с гейтом? Он чёрный и перегревается?

## Требования

При выборе этого триггера подключённые действия будут активироваться, только когда соседний двигатель находится на стадии перегрева.

## Направления триггеров

Гейт может показывать триггер «Перегрев двигателя» несколько раз разными цветами, обозначая каждый из подключённых двигателей.

Цвет триггера соответствует направлению двигателя относительно трубы, чтобы вы могли различать каждый двигатель.
