# Двигатель жёлтый

Какого цвета двигатель рядом с гейтом? Жёлтый?

## Требования

После выбора подключённые действия будут активироваться, только когда соседний двигатель находится на жёлтой температурной стадии.

## Направления триггеров

Гейт может показывать триггер «Двигатель жёлтый» несколько раз в разных цветах — по одному для каждого из подключённых двигателей.

Цвет триггера обозначает направление, в котором находится двигатель относительно трубы, чтобы вы могли различать каждый из них.
