# Резервуар пуст

Пуста ли цистерна рядом с гейтом?

## Требования

После выбора подключённые действия будут активироваться, только когда во всех подключённых цистернах не останется жидкости.

## Направления триггеров

Гейт может показывать триггер «Резервуар пуст» несколько раз в разных цветах — по одному для каждой из подключённых цистерн.

Цвет триггера обозначает направление, в котором находится цистерна относительно трубы, чтобы вы могли различать каждую из них.
