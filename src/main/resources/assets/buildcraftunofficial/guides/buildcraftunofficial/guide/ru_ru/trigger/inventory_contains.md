# Инвентарь не пуст

Есть ли этот предмет в сундуке рядом с гейтом?

## Требования

После выбора подключённые действия будут активироваться, только когда в подключённом инвентаре есть предметы.

## Параметры

Если у триггера «Инвентарь не пуст» и установленного гейта доступны параметры, слоты фильтра рядом с ним становятся доступными как параметр.

Разместив предметы в слотах фильтра, вы можете перед срабатыванием проверить, есть ли в инвентаре любые из предметов, выбранных в слотах фильтра.

## Направления триггеров

Гейт может показывать триггер «Инвентарь не пуст» несколько раз в разных цветах — по одному для каждого подключённого инвентаря.

Цвет триггера обозначает направление, в котором находится инвентарь относительно трубы, чтобы вы могли различать каждый из них.
