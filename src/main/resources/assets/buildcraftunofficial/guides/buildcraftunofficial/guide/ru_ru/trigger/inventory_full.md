# Инвентарь полон

Эх, если бы существовал способ проверить, полон ли сундук.

## Требования

После выбора подключённые действия будут активироваться, только когда в каждом подключённом слоте инвентаря есть предмет.

## Направления триггеров

Гейт может показывать триггер «Инвентарь полон» несколько раз в разных цветах — по одному для каждого подключённого инвентаря.

Цвет триггера обозначает направление, в котором находится инвентарь относительно трубы, чтобы вы могли различать каждый из них.
