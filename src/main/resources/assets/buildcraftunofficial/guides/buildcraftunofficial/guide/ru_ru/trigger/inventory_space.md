# В инвентаре есть место

Есть ли в сундуке рядом с гейтом ещё место для предметов?

## Требования

После выбора подключённые действия будут активироваться, только когда в подключённом инвентаре есть пустые слоты, чтобы принять предметы.

## Параметры

Если у триггера «В инвентаре есть место» и установленного гейта доступны параметры, слоты фильтра рядом с ним становятся доступными как параметр.

Разместив предметы в слотах фильтра, вы можете перед срабатыванием проверить, есть ли в инвентаре пустые слоты или незаполненные слоты, в которые могут поместиться предметы, выбранные в слотах фильтра.

## Направления триггеров

Гейт может показывать триггер «В инвентаре есть место» несколько раз в разных цветах — по одному для каждого подключённого инвентаря.

Цвет триггера обозначает направление, в котором находится инвентарь относительно трубы, чтобы вы могли различать каждый из них.
