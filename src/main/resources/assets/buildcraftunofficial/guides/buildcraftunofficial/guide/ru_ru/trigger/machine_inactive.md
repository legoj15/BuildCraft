# Работа завершена

Действительно ли у машины рядом больше нет работы, которую она могла бы выполнять?

## Требования

После выбора подключённые действия будут активироваться, только когда соседняя машина завершила всю работу, которую она могла бы выполнять.

Примечание: не все машины поддерживают триггер «Работа завершена».
