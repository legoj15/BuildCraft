# Требуется энергия

Нет смысла подавать энергию в трубу, из которой её никто не пьёт.

## Требования

После выбора подключённые действия будут активироваться, пока хотя бы одно устройство ниже по потоку в сети труб запрашивает энергию. Используйте его для управления двигателями, чтобы они работали, только когда что-то действительно потребляет энергию, — это экономит топливо и предотвращает бесполезные излишки.

## Совместимость с трубами

Триггер считывает текущее значение запроса энергии из обработчика потока трубы. Он работает как на кинетических трубах MJ, так и на FE-трубах — обработчик потока сообщает о запрошенной, но не доставленной энергии, какой бы тип труба ни передавала.
