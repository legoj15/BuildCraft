# Сигнал редстоуна выкл.

Разве гейт не получает сигнал редстоуна?

## Требования

После выбора подключённые действия будут активироваться, только когда блок, на котором установлен гейт, не получает сигнал редстоуна.

## Параметры

Когда у триггера «Сигнал редстоуна выкл.» и у установленного гейта есть доступные параметры, «Только со стороны гейта» становится доступным в качестве параметра.

Выбор параметра «Только со стороны гейта» означает, что будет проверяться, не получает ли сигнал редстоуна только та сторона, на которой установлен гейт.
