# Robot In Station

Is a robot sitting on this station right now?

## Requirements

Visiting robots count as well as the station's own: a Carrier loading cargo, a Tank robot emptying, or a robot recharging on a kinesis pipe all make it fire. It takes no parameter; to tell robots apart, keep them on separate stations.
