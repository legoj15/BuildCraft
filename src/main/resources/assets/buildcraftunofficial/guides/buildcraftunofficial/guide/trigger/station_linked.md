# Station Linked

Does a robot call this station home, and is it here?

## Requirements

A robot is linked to the station it was placed on; that station is its home and the one whose gate gives it orders. The trigger fires only for that robot, not for visitors. Compare Station Reserved, which fires for any robot using the station.
