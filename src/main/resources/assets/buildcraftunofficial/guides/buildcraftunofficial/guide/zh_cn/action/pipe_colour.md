# 染色传输物品

青金石运输管道和靛金刚运输管道可以让你染色/分拣已染色的物品，此动作可以更改染色/分拣所用的颜色。

## 需求

该动作激活后，门会相应地调整管道：

青金石运输管道会将经过管道的物品染成“染色物品”动作所选的颜色。

靛金刚运输管道仅会将已被染成“染色物品”动作所选颜色的物品送往所选的方向。

- [靛金刚运输管道](../pipe/daizuli_item.md)
