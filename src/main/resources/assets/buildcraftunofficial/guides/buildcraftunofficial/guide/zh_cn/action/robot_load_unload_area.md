# Load or Unload in Area

在这边取货送货，在那边干活。

## 信息

若没有该动作，机器人会在其工作区域内寻找“提供物品”和“接受物品”对接站。在该动作的参数槽中放入定位图纸后，搜索便会转至那个区域进行（无论哪种情况，机器人自己的母站都能接收它的货物），这样一来，伐木工板便能砍伐一片森林，再把工具和原木运送到别处的仓库。参数槽需要石英门或钻石门。
