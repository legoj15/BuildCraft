# 强制机器人

只有你。

## 信息

用一只已编程的机器人点击参数槽位，或用空手点击以在各块电路板之间循环切换，对接站就会预留给这一类机器人；其他机器人一律被拒之门外。它很适合用来让骑士板的剑箱远离屠夫板，或为真正要紧的机器人留出一个空闲的充电对接站。它不会交出已有其他机器人居住的对接站：住在那里但类型不符的机器人会离开，但该站仍是它的母站，其他任何机器人都不能使用。要释放该站，请先拿起住在那里的机器人，再把另一只机器人放上去。槽位为空时，所有机器人都会被拒之门外。参数槽位需要石英门或钻石门。
