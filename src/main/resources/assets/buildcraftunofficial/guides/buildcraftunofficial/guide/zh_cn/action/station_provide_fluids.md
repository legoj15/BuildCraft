# 提供流体

在这里加满。

## 信息

与“提供物品”类似，该动作只有通过木质流体管道才能生效，且管道的提取面必须朝向储罐。在参数槽中放入流体容器可以限制所提供的流体。储罐机器人会在这里加满。该动作需要门正在触发才会生效；通常做法是使用一个恒为真的触发器（例如附近没有红石时的“红石信号关”）来让它持续生效。
