# 装配台

<ItemImage id="buildcraftunofficial:assembly_table" scale="2" float="right" />

手工合成与机械成形对材料的加工终究有限。好在聚焦之光的力量足够精密：你不仅能把方块切成一个个单独的面，甚至还能在芯片上蚀刻出精细的电路！

## 信息

界面**左侧**的 3×4 网格是材料缓冲区。材料可以从装配台的任意一面放入。

界面**右侧**的 3×4 网格是配方目录。只要缓冲区的内容与任何已注册的装配配方相符，该配方的产物就会出现在目录中。一旦接入了有效的能量来源，点击某个产物一次即可将其加入队列。多个配方可以同时排队：亮红色边框表示当前正在处理的配方，暗红色边框表示已排入队列。要暂停、跳过或移出队列中的某个配方，再次点击它即可，此时会出现灰色边框。

装配台已积累的 MJ 会留在其内部电池中，因此当焦点切换到另一个配方时，新配方会从进度条中已有的进度继续，而不是从零开始。

产物会从任意一面弹出到相邻的容器或管道中；若无处可放，则会散落到世界中。

## 能量

与[高级工作台](./advanced_crafting_table.md)一样，装配台是激光的供能目标。将一台或多台激光对准它，它们便会填充界面左缘的进度条。激光越多，分批处理就越快。

各配方的成本跨越三个数量级。透镜插件、光线感应器、计时器和门设拷贝器处于最便宜的一档（500 MJ）；管道脉冲器插件和基础门插件约为 1,000 MJ。管线每次合成消耗 5,000 MJ，产出 8 根。芯片则属昂贵一档：红石芯片 10,000 MJ，铁质芯片 20,000 MJ，金质芯片 40,000 MJ，石英芯片 60,000 MJ，钻石芯片 80,000 MJ。JEI 会在每个配方页面上显示对应的成本。

## 它能制作什么

**芯片：**红石芯片、铁质芯片、金质芯片、石英芯片和钻石芯片。它们是制作管道可插拔组件的基础级合成材料。

**可插拔组件：**管道脉冲器（由门驱动的引擎助推器）、光线感应器（基于光照等级的触发源）、计时器（三挡速率的时钟）、门设拷贝器（在门之间克隆门逻辑），以及每种染料颜色的透镜/滤镜透镜变体。

**管线：**全部十六种染料颜色的管线，每批 8 根。管线可将不同管道上的门连成一个统一的信号网络。

**门：**铁质、地狱砖质和金质材料的基础与门/或门插件，外加可将基础门升级为更强变体的修饰升级（青金石、石英、青金石+石英、钻石）。

**伪装板：**几乎所有方块的装饰外壳，安装到管道上即可让管道伪装成该方块。
