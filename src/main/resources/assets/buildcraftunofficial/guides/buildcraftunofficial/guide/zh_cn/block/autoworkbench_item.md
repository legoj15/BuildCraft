# 自动合成台

<ItemImage id="buildcraftunofficial:autoworkbench_item" scale="2" float="right" />

身为工程师，自动化一切便是你的天职。手动合成是件苦差事，那何不把它自动化呢？

## 信息

自动合成台是一种自动合成物品的方式，无需你亲自动手。只需设置好想要合成的物品的配方，再用管道将物品输入其中即可。

<Row>
<RecipesFor id="buildcraftunofficial:autoworkbench_item" fallbackText="" />
</Row>

只需将其中配方所需的资源用管道送入自动合成台，它便会缓慢地合成出对应的物品/方块，且不消耗任何能量。
