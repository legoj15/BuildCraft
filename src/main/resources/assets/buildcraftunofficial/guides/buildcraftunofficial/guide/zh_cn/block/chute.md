# 滑槽

<ItemImage id="buildcraftunofficial:chute" scale="2" float="right" />

基础的漏斗虽然不错，但功能有限，也没什么新意。

## 信息

滑槽（原名“漏斗”）是一种快速的单方块物品容器，能够将物品直接插入管道，也可以同时向各个方向（包括向上）的多个物品容器中插入物品。

</Row>

**用于合成:** <ItemLink id="buildcraftunofficial:builder" />

与漏斗类似，当物品掉落在滑槽上方，或位于滑槽下方且滑槽正对着它时，滑槽能够将这些物品从地面慢慢捡起。用红石引擎为其供能可以加快这一速度。
