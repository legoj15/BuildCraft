# 液闸

<ItemImage id="buildcraftunofficial:flood_gate" scale="2" float="right" />

在许多大型建筑项目中，用流体淹没大片区域是件枯燥乏味的苦差事，能免则免。

## 信息

液闸是一种不消耗能量的机器，当有流体经由管道输入时，它便会将流体向下放置到世界中
