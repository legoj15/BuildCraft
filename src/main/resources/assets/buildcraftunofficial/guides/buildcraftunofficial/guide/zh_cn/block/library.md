# 电子档案馆

<ItemImage id="buildcraftunofficial:library" scale="2" float="right" />

你所有的[蓝图](../item/blueprint_clean.md)和[模板](../item/template_clean.md)在箱子里无法堆叠——与其如此，不如把它们存入这个如同末影箱一般运作的数字数据库！

## 信息

屏幕左侧的大窗口是已保存的蓝图与模板（又称快照）的列表。点击其中一条即可将其选中，随后便可下载其数据或将其删除。

右侧的两排槽位负责执行传输：

- **顶行——下载（←）**：在右侧槽位插入一个已使用的快照。数据加载入档案馆时，箭头从右向左填充；完成后，同一物品会从左侧掉出，表示操作已经完成。此后该快照便会出现在列表中。
- **底行——上传（→）**：先在列表窗口中选中一个快照，再在左下角的槽位插入一个快照物品。箭头从左向右填充，选中的蓝图会写入（或覆盖）你的输入物品，完成后出现在右下角的槽位。
