# 路径标

<ItemImage id="buildcraftunofficial:marker_path" scale="2" float="right" />

这项替代技术不再将你束缚于体积，而是让你能够定义斜向定向路径。

## 信息

要将路径标相互连接，手持记号扳手，便能看见潜在的连接。

- [记号扳手](../item/marker_wrench.md)

将记号扳手对准其中一条连接并进行交互，它就会在这两个路径标之间创建出路径。与路径标本身交互则可以改变路径的方向。
