# 替换器

<ItemImage id="buildcraftunofficial:replacer" scale="2" float="right" />

蓝图已经到手，可你却希望当初用的是石头而不是圆石……与其重新建造、再架设一次建筑工作台，不如直接在蓝图里把所有圆石都替换掉！

## 信息

将带有快照数据的[蓝图](../item/blueprint_clean.md)插入顶部槽位。下方是两个[单方块示意图](../item/schematic_single_used.md)槽位：**左侧**是要查找的方块，**右侧**是用来替换的方块。此时你还可以重命名蓝图。

替换瞬间完成，无需能量。

顶部的 3D 预览会旋转展示蓝图的实时模型，让你在替换发生之前就能看到更改后的结果。
