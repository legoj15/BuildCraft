# 空白板

一块没有任务的板子。程控台免费提供它，也就是说，它提供的其实是“保持你的板子原样不动”。

## 行为

携带空白板的机器人没有任务，也无法被放置到对接站上；游戏会答复“未编程”。请先写入一块真正的板子。
