# 农夫板

不播种，不收割：只管翻耕。

## 行为

机器人会从其区域内的“提供物品”对接站装备一把锄头，并翻耕它在那里找到的每一块泥土或草方块。它会拒绝耐久耗尽的锄头，另取一把新的。为其编程需要 3,200 MJ。
