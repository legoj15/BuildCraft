# 落叶修剪板

一把长着翅膀的剪刀。树木理个发；树干是别人的活儿。

## 行为

机器人会从其区域内的一座“提供物品”对接站装备剪刀，并剪掉它在那里发现的每一个树叶方块。掉落物会落在地上。为其编程需要 3,200 MJ。
