# 伐木工板

给它一把斧头和一片森林，稍后再回来，便能收获一片空地。

## 行为

机器人会先从其区域内一座门的“提供物品”动作处于激活状态的对接站处装备一把斧头，然后砍伐它在区域内够得着的每一根原木。原木会掉落在地上；机器人并不收集它们。斧头用坏时它会再取一把，而没有斧头或没有原木时，它便会休眠。为其编程需要 3,200 MJ。
