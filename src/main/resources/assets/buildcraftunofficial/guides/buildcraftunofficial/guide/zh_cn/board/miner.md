# 矿工板

一位在矿井里从不睡觉的探矿者——只在栖木上才睡。

## 行为

机器人会从其区域内的一座“提供物品”对接站装备一把镐，然后开采它在区域内发现的矿石。它只会开采手中镐所能开采的矿石：木镐只能挖煤和下界金，石镐增加了铁、铜和青金石，铁镐则再加上金、红石、钻石和绿宝石。只有矿石方块才算数；石头、黑曜石和其他方块永远不会被碰。掉落物会掉在矿石原来的位置。为其编程需要 3,200 MJ。
