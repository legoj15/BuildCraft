# 抽水板

一台主动找上水洼的液泵，而不是坐等水洼找上门的那种。

## 行为

机器人会在区域内寻找流体源方块，飞到它跟前将其泵入自己的储罐，然后逐桶运往门上启用了“接受流体”的对接站。这座对接站必须位于工作区域内；若母站的门设置了“装载/卸载区域”，则位于该区域内亦可。机器人自己的母站即使处在区域之外，也同样算数。它不需要任何工具。为其编程需要 3,200 MJ。
