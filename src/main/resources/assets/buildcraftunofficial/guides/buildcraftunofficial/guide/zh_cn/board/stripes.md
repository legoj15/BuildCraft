# 条纹板

呃……条纹！一根站起来飞走的条纹运输管道。

## 行为

机器人会从其区域内的一座“提供物品”对接站取来任意物品，在区域内找一块空闲的空气方块，然后像[条纹运输管道](../pipe/stripes_item.md)那样在该处使用该物品：方块会被放置、种子会被种下、桶会被倒空，等等。它会不断重复，直到对接站被取空。为其编程需要 12,800 MJ。
