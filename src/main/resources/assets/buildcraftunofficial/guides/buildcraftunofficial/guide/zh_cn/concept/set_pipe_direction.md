# Set Pipe Direction

有些管道的功能与其朝向相关，例如[铁质运输管道](../pipe/iron_item.md)，或是带多个提取源的[木质运输管道](../pipe/wood_item.md)——它们的工作方向可以通过相连的门来更改。这通过最多 6 个动作实现，每个朝向各对应一个动作。

这些名称的颜色编码与钻石运输管道彩色方向面的颜色一致。

对于[靛金刚运输管道](../pipe/daizuli_item.md)以外的管道，门中可用的管道方向仅限于该管道当前的连接方向；如果一根铁质运输管道只沿东西方向成一条直线、别无其他连接，那么可用方向就只有东和西。一根四个基本方位以及顶部和底部都有有效连接的管道，则会在门中显示全部 6 个可设置的方向。
