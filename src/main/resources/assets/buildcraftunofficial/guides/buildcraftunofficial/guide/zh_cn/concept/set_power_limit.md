# Set Power Limit

铁质和钻石能量管道的各款变体会对流经其中的能量进行节流。连接其上的门可以随意调高或调低节流量，将管道的传输上限切换为另一个速率。

## 行为

MJ 动能管道（[铁质动能管道](../pipe/iron_power.md)和[钻石动能管道](../pipe/diamond_power.md)）提供七个 MJ/t 动作，从管道的最高传输速率一直降到 0 MJ/t。FE/RF 管道（[铁质 FE 管道](../pipe/iron_rf.md)和[钻石 FE 管道](../pipe/diamond_rf.md)）则以 RF/t 为单位提供同样的七档。选中 0 速率的条目会彻底阻断流经该管道的所有能量传输。

- [铁质动能管道](../pipe/iron_power.md)
- [钻石动能管道](../pipe/diamond_power.md)

启用 FE 兼容后可用：

- [铁质 FE 管道](../pipe/iron_rf.md)
- [钻石 FE 管道](../pipe/diamond_rf.md)

每个条目上显示的实际数值取决于管道本身。每种管道的门只会提供与其自身传输表相符的那七个动作。
