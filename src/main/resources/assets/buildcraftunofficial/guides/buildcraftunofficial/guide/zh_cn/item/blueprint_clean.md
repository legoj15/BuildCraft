# 蓝图

<ItemImage id="buildcraftunofficial:blueprint_clean" scale="2" float="right" />

它是你捕捉结构中最细微细节的媒介。将其插入[建筑工作台](../block/architect.md)即可捕获其视野内的一切，再把它装进[建筑机](../block/builder.md)，就能制造出一份精确的复制品。

## 信息

将蓝图插入与地标标定区域绑定的建筑工作台的输入槽位。扫描完成后，输入的蓝图即被使用（无论它是空白的还是已使用过的），并被放入输出槽位，此时新的数据已写入其中。蓝图的工具提示中会显示名称以及所捕获结构的 3D 快照。

要部署已保存的结构，可将蓝图插入[建筑机](../block/builder.md)，并为其提供蓝图捕获时所用的相同资源。

如果只需要结构的大致形状，请参阅[模板](./template_clean.md)，它的扫描更快、建造更简单。
