# 体积盒

<ItemImage id="buildcraftunofficial:volume_box" scale="2" float="right" />

体积盒仅在创造模式或开启作弊时可用。你可以用体积扳手对它进行操作。

- [体积扳手](./volume_wrench.md)

用体积扳手点击你想要移动的那个角，然后朝你指向的位置移动，盒子的大小就会随你一起移动。

在你想让它停止移动的地方再次用扳手单击，它就会停止。你还可以用体积扳手或记号扳手潜行单击它，将体积盒完全移除

*仅创造模式：没有生存模式的合成配方。*
