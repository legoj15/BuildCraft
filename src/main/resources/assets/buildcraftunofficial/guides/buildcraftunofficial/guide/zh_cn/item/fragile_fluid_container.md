# 脆弱流体容器

<ItemImage id="buildcraftunofficial:fragile_fluid_container" scale="2" float="right" />

破损物体内所装的流体不会漫出泼洒，也不会蒸发到空气中，而是被封存在被破坏方块的碎粒之中。

## 信息

脆弱流体碎片是一种以物品形式储存流体的方式。破坏一个含有流体的 BuildCraft 方块时，其中容纳的所有流体都会以流体碎片的形式掉落，并被分割成若干 500 mB 的物品。流体碎片可以像使用桶那样被放回储罐或机器中。流体碎片一旦完全排空就会被丢弃。流体碎片无法重新填充。
