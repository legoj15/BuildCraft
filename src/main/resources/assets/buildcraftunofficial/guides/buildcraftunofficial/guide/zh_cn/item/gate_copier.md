# 门设拷贝器

<ItemImage id="buildcraftunofficial:gate_copier" scale="2" float="right" />

多次手写相同的文本十分乏味，配置门也是如此。既然文本可以复制粘贴，门为什么不行呢？

## 信息

与门交互即可复制它当前的配置。工具的外观会发生变化，并通知你信息已复制。粘贴同样简单：手持门设拷贝器，与你希望采用相同配置的各个门交互即可。要清除已复制的数据，请潜行并交互手持的门设拷贝器，这样就能复制其他配置。
