# BuildCraft 指南书

<ItemImage id="buildcraftunofficial:guide" scale="2" float="right" />

在你建造想象中最宏伟基地的征程中，弄清手边有哪些可用的工具和机器往往大有用处。

这本书包含了大量与 BuildCraft 模组相关的信息。目录页按用途对一切内容进行分组：能源、运输、门与逻辑、建造、采矿与流体、硅电子和机器人。目录页顶部的按钮可以切换到按事物种类（方块、物品、管道、触发器、动作）排列的列表，或一个纯字母顺序的列表；搜索页签则能找到任何物品，甚至是来自其他模组的物品。

我们希望你能在这个模组中收获与原作同样多的乐趣。这是 BuildCraft Redux，一个由粉丝制作的原作延续项目。如果你有任何问题或疑问，请在移植版的[GitHub issue 跟踪器](https://github.com/legoj15/BuildCraft/issues)上报告。

感谢 BuildCraft 背后的原作团队，以及让这个模组从 1.2.5 一路延续到 1.12.2 的维护者们——它是我童年中重要的一部分，我希望更多人也能体验到它。
