# 记号扳手

<ItemImage id="buildcraftunofficial:marker_wrench" scale="2" float="right" />

在创建路径或体积时，能够实时看到连接会带来极大帮助。

## 信息

记号扳手能做[基础扳手](./wrench.md)能做的一切，此外还能在标记连接生效之前查看这些连接，并追踪标记之间或标记与你之间的距离，方便规划。连接标记和操作标记盒不会消耗耐久度。

要将连接可视化并查看当前连接的长度，将工具拿在手中即可。要测量你与某个标记之间的距离，右键点击它并沿直线行走。准星下方会出现一个距离读数。这是你到该标记的距离，而不是总长度。即使将工具收起，距离读数也会继续显示。要清除它，可以完成标记之间的连接，或者朝空中右键点击。

要删除你创建的体积，可以破坏[地标](../block/marker_volume.md)、破坏所连接的机器，或者在标记已消失且没有配对机器的情况下，潜行并右键点击它。
