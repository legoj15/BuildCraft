# 管塞

<ItemImage id="buildcraftunofficial:plug_blocker" scale="2" float="right" />

为什么我的管道老是互相连接？该怎么阻止？在它们之间放一个管塞就行了。

## 管道连接

将它直接放置在管道的任意一面，之后在该面与其相邻的任何管道都不会连接。

可插拔组件只能放置在管道上，并且可以放置在管道的任意一面。
