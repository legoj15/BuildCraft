# 伪装板

<ItemImage id="buildcraftunofficial:plug_facade" scale="2" float="right" />

管道与你的建筑风格不搭？只需放上一块由方块制成的伪装板来搭配建筑，把它们隐藏起来。

## 伪装板变体

游戏中的几乎所有方块都可以制成伪装板，并放置到管道的侧面。

实心伪装板如果放在两根管道之间，会阻断管道之间的连接。

中空伪装板则允许管道连接穿过它。
