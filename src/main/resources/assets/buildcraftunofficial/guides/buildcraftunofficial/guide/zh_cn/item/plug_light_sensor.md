# 光线感应器

<ItemImage id="buildcraftunofficial:plug_light_sensor" scale="2" float="right" />

有了光线感应器，你就可以利用光的力量来控制你的门。

## 可插拔组件机制

这些数据让相邻的门能够通过明亮和黑暗触发条件检测当前是亮还是暗。

这些明亮和黑暗触发条件可以通过门来触发动作。

- [Light Bright](../trigger/light_high.md)
- [Light Dark](../trigger/light_low.md)

## 管道连接

可插拔组件只能放置在管道上，并且可以放置在管道的任意一面。

当它被放置在两根管道之间时，会阻止这两根管道之间任何其他管道和管线的连接。
