# 管道脉冲器

<ItemImage id="buildcraftunofficial:plug_pulsar" scale="2" float="right" />

不用大型引擎就能免费驱动你的管道？这多酷啊。

## 可插拔组件机制

它只能放置在接受能量的管道上，右键点击即可将其激活。

也可以使用门上的脉冲器动作来激活管道脉冲器。

- [能量脉冲](../action/power_pulsar.md)
- [单次能量脉冲](../action/single_power_pulse.md)

## 管道连接

可插拔组件只能放置在管道上，并且可以放置在管道的任意一面。

当它放置在两根管道之间时，会阻止其他任何管道以及管线之间的连接。
