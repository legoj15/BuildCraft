# 计时器

<ItemImage id="buildcraftunofficial:plug_timer" scale="2" float="right" />

让时钟与管道逻辑协同工作，从而使它们变得更加实用！

## 信息

计时器可以放置在任何管道的任意一面。当它与门共用一根管道时，会为门提供三个可用的触发条件。

- [5 秒计时器](../trigger/timer_short.md)
- [10 秒计时器](../trigger/timer_medium.md)
- [15 秒计时器](../trigger/timer_long.md)
