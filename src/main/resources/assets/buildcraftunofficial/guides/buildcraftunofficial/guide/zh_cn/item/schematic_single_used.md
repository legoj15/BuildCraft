# 单方块示意图

<ItemImage id="buildcraftunofficial:schematic_single_used" scale="2" float="right" />

一份简单到可以手工读写的蓝图。拥有一份精确的副本能有多少用途，你一定会感到惊讶！

## 信息

手持空白示意图与任意方块互动，该方块的信息就会被写入其中。只要物品栏中有足够的资源，就可以用它手动放置与该方块完全相同的副本；也可以在替换器中放入两张不同的单方块示意图，用它替换蓝图中已有的方块。

- [替换器](../block/replacer.md)

要清空单方块示意图以便另作他用，请潜行并与之互动。

如果你想精确复制整个结构，或者只需要它的大致形状，请参阅蓝图和模板。

- [蓝图](./blueprint_clean.md)
- [模板](./template_clean.md)
