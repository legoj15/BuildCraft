# 模板

<ItemImage id="buildcraftunofficial:template_clean" scale="2" float="right" />

有时，你只是需要又快又糙地搭起点什么，并不在乎它最终是用什么做成的，只想要那个形状，而你需要的不过是某种模板……

## 信息

将模板插入与地标标定区域绑定的[建筑工作台](../block/architect.md)的输入槽位。扫描完成后，输入的蓝图即被使用（无论它是空白的还是已使用过的），并被放入输出槽位，此时新的数据已写入其中。蓝图的工具提示中会显示名称以及所捕获结构的 3D 快照。

要部署已保存的结构，可将蓝图插入[建筑机](../block/builder.md)，并为其提供蓝图捕获时所用的相同资源。

如果需要 1:1 地还原每一个方块，甚至连箱子的内容物也一并保留，请参阅[蓝图](./blueprint_clean.md)。
