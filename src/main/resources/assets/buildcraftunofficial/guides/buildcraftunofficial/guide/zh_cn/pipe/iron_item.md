# 铁质运输管道

<ItemImage id="buildcraftunofficial:pipe_iron_item" scale="2" float="right" />

想让物品只朝一个方向输送？只需设定好管道的方向，把它们输送过去即可。

## 管道机制

物品会经由实体侧面进入，再朝透明的那一面输出。

物品的前进方向可以这样更改：用扳手敲打你想让物品流向的铁质运输管道那一侧、给它通上红石信号，或者使用门。

物品不会沿来路返回，只会朝其他方向前进。

如果输送中的物品无处可去，就会来回弹动，不断尝试朝设定的方向前进。

某些机器可以自动将物品直接输出到铁质运输管道中，无需再经由供能的提取管道输送。

使用管塞或给管道刷上不同的颜色，都可以阻止管道相互连接。
