# 容器有空间

它旁边的箱子里还有空间放更多物品吗？

## 需求

选中后，只有当所连接的容器有空置槽位可以接收物品时，所连接的动作才会被激活。

## 参数

当选择了“容器有空间”且所安装的门带有可用参数时，其旁的过滤槽位便会作为参数开放。

在过滤槽位中放入物品，即可在触发前检查容器中是否有空置槽位，或是仍能接收过滤槽位中所选物品的未满槽位。

## 触发方向

门可能会以不同颜色多次显示“容器有空间”触发条件，以代表各个不同的已连接容器。

触发条件的颜色代表容器相对于管道的方位，这样你就能区分每一个容器。
