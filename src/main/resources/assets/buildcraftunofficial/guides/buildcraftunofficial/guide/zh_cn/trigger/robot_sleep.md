# Robot Sleep

这座对接站上的机器人睡着了吗？

## 需求

机器人在无事可做或缺少做事所需之物时，便会停到母站上休眠，一分钟后醒来重新寻找。该触发条件让门能够留意到这段闲置时间：可以把它与“唤醒”搭配使用，也可以用一道管道信号，告知基地的其他部分机器人正在等待。
